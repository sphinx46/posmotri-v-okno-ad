# Посмотри в окно

Учебный проект Яндекс Практикума о том, как выглядят разные города в разное время суток. В приложении можно найти видео по названию города, выбрать утро, день или ночь и переключаться между роликами в списке. Кнопка «Показать ещё» загружает следующую подборку.

Интерфейс свёрстан по макету на HTML и CSS. Поиск, загрузка карточек и переключение роликов работают на JavaScript.

## Локальный запуск

Запустите HTTP-сервер из корня проекта. Для команды нужен Python 3.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте [локальную страницу проекта](http://127.0.0.1:8765/). Для загрузки каталога и воспроизведения роликов нужен доступ к API Практикума. При сбое загрузки приложение показывает сообщение об ошибке.

[Репозиторий на GitHub](https://github.com/sphinx46/posmotri-v-okno-ad)
